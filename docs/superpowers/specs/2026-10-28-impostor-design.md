# Impostor — 이물 간섭 검출 비교 툴 설계

작성일: 2026-10-28

## 1. 목적

산업용 3D 비전 검사(자동차 부품 정합)에서 부품 위에 케이블·커넥터·비닐봉지 같은 이물이 올라오면 정합이 틀어지거나 체결이 실패한다. 이를 2D 이미지로 미리 잡아낼 방법을 찾고 있다.

이 툴은 **여러 검출 방법을 같은 데이터에 돌려 보고, 실제 검사 프로그램(CleVisionSystems, C# WPF)에 넣을 방법을 고르기 위한 개발자용 실험대**다. 현장 라인에서 쓰는 도구가 아니다.

배경:
- FEM 클립(P2)에서 직접 구현한 PatchCore 이상탐지가 LH 간섭 15건 중 14건 검출, 정상 오검출 0/30을 냈다 (`C:\DATA\EV\FEM\clip\anomaly`).
- 3D 높이 기반 규칙(막힘 비율)은 판에 납작하게 붙은 비닐을 놓쳐 접었다.
- 간섭 사례는 드물고(FEM 16장, SeatLongRail ~10건) 이물 종류가 매번 다르다. 정상 이미지는 수백 장 있다.

## 2. 목표 / 비목표 / 피해야 할 것

**목표**
- 화면에서 데이터셋과 알고리즘을 골라 실행하고, 알고리즘별 성적을 나란히 비교한다.
- 판단 기준 세 가지를 보여준다: **놓친 간섭 건수**, **정상 오검출 건수**, **히트맵(또는 박스)이 실제 이물 위치를 짚는지**.
- 툴 안에서 이미지에 정상/간섭 라벨을 달고, 이물에 박스를 그린다.
- 특정 차종·부품에 한정되지 않는다. 어떤 폴더·카메라·마스크 조합이든 데이터셋으로 만들 수 있다.

**비목표 (1차 범위 밖)**
- 실행 기록 저장·과거 결과 비교 (사용자 결정: 처음엔 가볍게)
- CleVisionSystems 연동, ONNX 내보내기
- 3D 점군 사용, PaDiM·EfficientAD 등 다른 알고리즘 (나중에 추가할 수 있게만 구조를 둔다)
- 여러 사용자, 원격 접속

**피해야 할 것**
- 원본 이미지를 복사해 사본을 만드는 것 (원본 경로만 참조)
- 성능은 맞는데 자동 임계값이 정상을 NG로 띄우는 쪽으로 기우는 것 — 현장에서는 **정상인데 NG가 떠서 라인이 서는 것이 간섭을 놓치는 것보다 치명적**이다 (사용자 판단)

## 5. 설계 (작성자 판단 — 사용자가 직접 정한 것 아님)

### 5.1 형태
- **Python 데스크톱 앱, PySide6(Qt)** (사용자 결정: 웹페이지가 아니라 창으로 띄우는 툴). 학습·추론과 화면이 한 프로그램 안에서 돈다.
- 이미지 보기·박스 그리기는 QGraphicsView(확대·이동 포함), 결과 표는 QTableView, 임계값은 QSlider.
- 학습·추론은 수 분 걸리므로 작업 스레드(QThread 등)에서 돌리고 진행률을 표시한다. 그동안 화면이 멈추면 안 된다.
- 실행: `python -m impostor` (필요하면 바탕화면 바로가기).
- 레포 위치: `C:\Users\HONGEUNSEO\source\repos\impostor` (git init, 원격 없음)

### 5.2 데이터셋
- 데이터셋 = 이름 + 루트 폴더 + 파일 이름 패턴(glob, 예: `*/cam_03_IMG_Texture_8Bit.png`) + 마스크 PNG 경로.
- 데이터셋 정의와 라벨은 툴 작업 폴더에 데이터셋당 JSON 파일 하나로 저장: 이미지별 `원본 경로, 라벨(정상/간섭/미분류), 박스 목록`. 이미지 자체는 복사하지 않는다.
- 라벨 규칙: 박스를 하나라도 그리면 자동으로 "간섭". 정상은 직접 표시. 표시 안 한 건 "미분류".
- 가져오기: 이미 폴더로 나눠 둔 데이터(예: FEM `anomaly\data\normal`, `inside`, `edge`)는 하위 폴더 이름 → 라벨 매핑을 지정해 한 번에 가져온다. 박스는 없으므로 YOLO용으로는 나중에 그려야 한다.
- 한 데이터셋 = 마스크 하나. LH/RH처럼 마스크가 다르면 데이터셋을 나눈다.

### 5.3 라벨링 화면
- 이미지 목록(라벨별 필터, 개수 표시) + 큰 이미지 보기 + 마스크 윤곽 겹쳐 보기.
- 마우스 드래그로 박스 추가, 선택 후 삭제. 단축키로 정상/미분류 지정과 다음/이전 이미지 이동.
- 박스 종류(케이블/비닐 등)는 1차에 두지 않는다 — 클래스는 "이물" 하나.

### 5.4 알고리즘

공통 인터페이스: `train(학습 이미지들, 마스크)`, `score(이미지) → (이미지 점수, 위치 지도 또는 박스)`. 나중에 PaDiM 등을 같은 인터페이스로 추가.

**PatchCore** — 기존 `C:\DATA\EV\FEM\clip\anomaly\code\patchcore.py`를 이식한다.
- 백본 wide_resnet50(ImageNet), layer2+layer3 특징, 마스크 bbox로 잘라 폭 640으로 축소, coreset 20,000개
- 이미지 점수 = 마스크(5px 침식) 안 이상 지도 최댓값
- 학습: 정상만. 결과 = 이상 지도(히트맵)

**YOLO** — Ultralytics YOLOv8 (n 또는 s, 단일 클래스 "이물")
- 학습: 간섭 이미지의 박스 + 정상 이미지(배경, 박스 없음)
- 이미지 점수 = 마스크와 겹치는 예측 박스 중 최고 신뢰도 (없으면 0)
- 결과 = 예측 박스 (히트맵 자리에 박스를 그려 표시)
- 참고: Ultralytics는 AGPL-3.0. 사내 실험용으로는 문제없지만, 나중에 현장 프로그램에 넣을 때는 라이선스 검토가 필요하다.

### 5.5 평가
- **정상 분할 (두 알고리즘 공통)**: 정상 이미지를 **학습 60% / 임계값용 20% / 평가 20%**로 나눈다(고정 시드). 자동 임계값은 임계값용 세트로 정하고, 성적표의 오검출은 처음 보는 평가 세트에서 센다. 같은 세트로 임계값을 정하고 오검출을 세면 항상 0이 나와 의미가 없기 때문이다.
  - 같은 회차 폴더(같은 차량)에서 나온 이미지는 같은 쪽으로 묶어서 나눈다.
  - 이미지마다 "항상 학습" / "항상 평가" 고정을 지정할 수 있다 (예: 손글씨 판은 학습, 마스크 근처에 물체가 있는 어려운 정상은 평가). 고정하지 않은 것만 무작위로 나눈다.
- **이상탐지**: 학습 60%로 학습. 간섭 이미지는 전부 평가에만 쓴다.
- **YOLO**: 간섭 이미지가 적으므로 박스 있는 간섭을 k-겹으로 나눠 교차검증(k = min(5, 박스 있는 간섭 수)). 각 간섭 이미지는 자기를 학습하지 않은 모델로 평가된다. 정상 학습 60%는 배경 이미지로 학습에 넣는다.
  - 정상(임계값용·평가) 이미지는 k개 모델 점수 중 **최댓값**을 쓴다 (가장 보수적 — 정상 NG를 과소평가하지 않기 위해).
  - **박스 없는 간섭**은 학습에는 못 쓰지만 평가에는 넣는다(어느 겹 모델로 평가해도 처음 보는 이미지이므로, k개 점수의 평균). 그래야 놓침 분모 N이 PatchCore와 같아 나란히 비교된다. 박스 있는 간섭이 2장 미만이면 YOLO는 실행하지 않고 이유를 표시한다.
- **성적표 항목** (알고리즘당 한 줄): 놓침(n/N), 오검출(n/M), AUC, 임계값, 위치 적중(n/N), 이미지당 처리 시간
- **위치 적중**: 간섭 이미지에서 히트맵 최댓값 위치(또는 YOLO 최고 신뢰도 박스 중심)가 라벨 박스 안에 들어오면 적중. 박스가 없는 간섭 이미지는 위치 적중 계산에서 뺀다.
- **자동 임계값**: 임계값용 정상 점수의 최댓값 바로 위 (그 세트에서 정상 오검출 0건). 그 임계값으로 평가 세트의 놓침·오검출을 보여준다.
- **슬라이더**: 알고리즘마다 하나. 움직이면 놓침·오검출·이미지별 OK/NG가 바로 다시 계산된다(재실행 없음).

### 5.5.1 실행 시간 (사용자 결정: YOLO는 빠른 모드)
- 알고리즘은 각각 따로 실행할 수 있다. 한 번 학습한 결과는 앱이 켜져 있는 동안 메모리에 두어, 슬라이더·이미지 선택 때 다시 학습하지 않는다.
- YOLO 기본은 **빠른 모드**: 작은 모델(n), 적은 epoch, 겹 수 축소(예: k=3). 목표는 2080 Ti에서 YOLO 한 번 실행이 수 분 안에 끝나는 것. 구체 값은 빌더 재량.
- 정밀 모드(모델·epoch·k 확대)는 1차에서는 설정값으로만 열어 두고 UI 노출은 하지 않아도 된다.

### 5.6 결과 화면 (A안)
- 성적표 아래에 평가 이미지 목록(점수순, 놓침·오검출 강조). 하나를 누르면 원본 | PatchCore 히트맵 | YOLO 박스를 나란히, 라벨 박스도 겹쳐 표시.
- 실행 결과는 앱이 켜져 있는 동안 메모리에만 둔다. 앱을 끄면 사라진다.
- 학습은 수 분 걸릴 수 있으므로 진행 상황(단계·%)을 표시한다.
